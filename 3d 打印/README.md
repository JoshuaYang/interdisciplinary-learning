# 圆锥数学建模与 3D 打印教学任务

本课固定研究圆锥，三个方程系数均为 2：

$$\frac{X^2}{a^2}+\frac{Y^2}{b^2}-\frac{Z^2}{c^2}=0,\qquad a=b=c=2$$

即 $X^2/4+Y^2/4-Z^2/4=0$。这里使用大写坐标区分原始方程与程序内部坐标。

## 从无限双圆锥到有限打印模型

原式表示沿 Z 轴上下延伸的双圆锥，不能直接作为有限打印模型。选上半锥：

$$Z=c\sqrt{(X/a)^2+(Y/b)^2}$$

另设截取高度 **H = 2**，保留 $0\le Z\le H$。注意：c 是方程系数，H 才是截取高度；本课两者恰好均为 2。

为让模型底面朝下，将这一段圆锥翻转摆放。内部坐标为 $(x,y,z)=(X,H-Z,-Y)$，其中 y 表示高度：

$$y=f(x,z)=\max\left(0,H-c\sqrt{(x/a)^2+(z/b)^2}\right)$$

本课得到 $y=\max(0,2-\sqrt{x^2+z^2})$，尖顶为 $(0,2,0)$，底面为 y=0、半径 2 的圆。max 只是将边界外高度截为零；模型仅在底圆内采样。

引擎导出时转换为打印坐标 $(x,-z,y)$，使 STL 的 Z 轴朝上。SCALE=10，按毫米导入时，实物高 **20 mm**、底面直径 **40 mm**。

## 任务 1：二分逼近底圆边界

从 x=0 沿正 X 轴前进，高度从 2 下降至 0。由于截断函数在边界外也恒为零，任务是寻找“高度由正变零”的边界，而不是任意一个零点。

在 [0,20] 中二分：若 f(mid,0)>0，则更新 low；否则更新 high。区间长度小于容差后返回零高度一侧的 high（确保底边高度为零），结果应接近 2。

```bash
python3 tasks/task1_boundary.py
```

## 任务 2：中心差分求法向量

在斜面内部点 (x,z)=(1,0) 计算：

$$f_x\approx\frac{f(x+h,z)-f(x-h,z)}{2h},\quad f_z\approx\frac{f(x,z+h)-f(x,z-h)}{2h}$$

曲面 y-f(x,z)=0 的向外法向量为 $(-f_x,1,-f_z)$，除以模长后成为单位向量。测试点的结果应约为 $(1/\sqrt2,1/\sqrt2,0)$。尖顶和底圆截断边界不可直接当作光滑点求导。

此任务用于数学学习与自测；STL 引擎实际使用三角形边向量的叉积计算面法向量。法向量描述面的朝向，本项目不沿法向量加壁厚。

```bash
python3 tasks/task2_normal.py
```

## 任务 3：圆的参数方程与空间坐标

令 r 为归一化半径，theta 为弧度制角度：

$$x=Rr\cos\theta,\quad z=Rr\sin\theta,\quad y=f(x,z)$$

其中 R=2，r=0 对应尖顶，r=1 对应底圆。测试尖顶 (0,2,0)、底边 (2,0,0)，并观察 theta 改变时点沿圆周移动。

```bash
python3 tasks/task3_coords.py
```

## 运行与打印

在本文件所在目录执行：

```bash
python3 main.py
```

默认输出 model.stl，共 28,320 个三角形。引擎将侧面和底圆封闭成实体边界，不需要额外构造内壁。打印内部的填充比例由切片软件设置。

将 STL 导入打印机配套切片软件，确认高 20 mm、直径 40 mm、底面朝下，选择实际打印机与耗材配置，检查逐层预览后导出打印文件。
