# 从圆锥方程到 3D 打印：第一次课教学设计与讲义

授课对象：具备函数、三角函数基础的高中学生。课时：45 分钟。数学任务包括边界逼近、空间向量与圆的参数方程；中心差分作为拓展内容，不要求已有偏导数知识。

## 一、教学目标

1. 认识方程 $X^2/4+Y^2/4-Z^2/4=0$ 表示无限双圆锥，区分方程系数与截取高度。
2. 理解截取、摆放、采样、三角形拼接和补底形成实体的过程。
3. 理解三个 task 的输入输出，并运行单独自测与主程序。
4. 区分 STL 几何模型与切片后的打印路径。

## 二、课前准备

准备 Python 3 环境、项目文件、圆锥实物或示意图、打印机配套切片软件。教师课前运行三个 task 和 main.py，并检查生成模型尺寸。

本课固定 a=b=c=2、截取高度 H=2、SCALE=10，不提供碗、马鞍面等其他函数选项。当前任务文件是已完成的参考实现，教师可通过遮挡关键语句组织补全练习。

## 三、45 分钟课堂流程

### 1. 认识原始方程（8 分钟）

板书：

$$\frac{X^2}{a^2}+\frac{Y^2}{b^2}-\frac{Z^2}{c^2}=0,\quad a=b=c=2$$

化简得 $Z^2=X^2+Y^2$。当 Z 为正或负时，都有对应圆截面，因此这是双圆锥。

提问：Z=1 和 Z=2 的截面半径分别是多少？回答：1 和 2。追问：这个方程有没有指定最高点？没有，它无限延伸。

另设 H=2，仅取上半锥 0≤Z≤H。c=2 是方程系数，H=2 是另外选择的截取高度，二者含义不同。

### 2. 从截取圆锥到打印摆放（7 分钟）

原始上半锥的尖顶在原点，截面圆在 Z=H。为了底面贴热床，将其翻转摆放。

程序内部采用 y 为高度，坐标关系为：

$$(x,y,z)=(X,H-Z,-Y)$$

于是：

$$y=H-c\sqrt{(x/a)^2+(z/b)^2}=2-\sqrt{x^2+z^2}$$

代码通过 max(0,...) 截断边界外负高度，便于判断底圆边界；实际模型只在底圆内采样。引擎最后把内部坐标转为 (x,-z,y)，使打印坐标 Z 朝上。

板书流程：原始方程 → 取上半锥并截高 → 翻转摆放 → 采样三角网格 → 补底封闭 → 切片。

### 3. 三个数学任务（15 分钟）

**任务 1：找底圆边界（5 分钟）**

打开 tasks/task1_boundary.py。在 [0,20] 取中点，计算 f(mid,0)。正值说明仍在圆内，零值说明已到边界或圆外。反复缩小区间，逼近半径 2。

提醒：这里是在求“正值区与零值区的分界”，不是传统正负异号的求根例子。

**任务 2：求法向量（5 分钟）**

打开 tasks/task2_normal.py。用点两侧的函数值之差除以距离，近似两个方向的斜率。对 y=f(x,z)，构造 (-f_x,1,-f_z)，再除以模长。

在 (x,z)=(1,0) 处，法向量约为 (0.7071,0.7071,0)。不在尖顶和截断边界上套用光滑曲面的结论。

法向量表示面的朝向，不表示厚度。此 task 为数学练习；引擎导出三角面时，用两条边的叉积求面法向量。两种方法分别针对光滑曲面和离散三角形。

**任务 3：把圆周点放进空间（5 分钟）**

打开 tasks/task3_coords.py。使用 x=Rr cos(theta)、z=Rr sin(theta)，再代入 y=f(x,z)。这里 r 是 0～1 的比例，R=2 才是底圆半径。

让学生预测：r=0 是尖顶；r=1 是底边；r=0.5 时，高度为 1。theta 以弧度表示。

### 4. 运行与观察（12 分钟）

在“3d 打印”目录的终端依次执行：

```bash
python3 tasks/task1_boundary.py
python3 tasks/task2_normal.py
python3 tasks/task3_coords.py
python3 main.py
```

观察自测输出，并将 model.stl 导入切片软件。检查：高度 20 mm、底面直径 40 mm、底面朝下；逐层预览应呈逐渐缩小的圆形截面。

解释封闭性：侧面加底圆构成完整实体边界。模型无需额外生成内壁，打印外壁和内部填充由切片软件设置。本课不采用曲面偏移加厚方案。

解释 STL：每个三角形记录三个顶点和法向量；STL 不保存单位与打印参数，尺寸需在切片软件确认。选择实际打印机与耗材配置后，再导出打印路径。

### 5. 课堂检查（3 分钟）

请学生回答：

1. 原始方程为什么是双圆锥？为什么需要额外指定 H？
2. a=b=c=2 是否意味着模型高度必然为 2？（不是，高度来自截取范围。）
3. 二分法寻找的边界在哪里？（半径 2。）
4. 为什么补底？（使侧面与底面围成实体边界。）
5. 法向量和壁厚有什么区别？（法向量表示朝向，壁厚是材料的几何厚度。）

## 四、常见问题

| 问题 | 排查方法 |
|---|---|
| Python 公式报错 | 乘方用 **，乘法用 *；检查括号与缩进 |
| 找不到 config 或 tasks | 确认终端位于“3d 打印”目录，按上述命令运行 |
| 模型尺寸不符 | 检查 H=2、a=b=c=2、SCALE=10，以及切片软件单位与缩放 |
| 模型未贴热床 | 使用切片软件的放置到平台功能，确认圆形底面朝下 |
| 法向量结果异常 | 选择斜面内部点，避免尖顶与底边；检查归一化和符号 |

## 五、实现说明

外层任务由 main.py 统一调度。task1 和 task3 参与几何生成，task2 参与数学自测。engine/stl_writer.py 负责三角网格、叉积法向量、底盖和坐标转换。学生代码文件夹中的独立实现不参与这套流程。
