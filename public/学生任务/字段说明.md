# Molecule Configuration Field Specifications

All input files use the JSON format. Property values are case-sensitive.

---

## 1. Top-Level Properties

| Property | Type | Required | Description | Example |
| :--- | :--- | :--- | :--- | :--- |
| `name` | string | Optional | English chemical name | `"Methane"` |
| `formula` | string | Required | Formula (use `·` for radicals) | `"CH4"`, `"CH3·"` |
| `center` | string | Polyatomic | Symbol of the central atom | `"C"` |
| `neighbors` | string[] | Polyatomic | Symbols of peripheral atoms | `["H", "H", "H", "H"]` |
| `atoms` | string[] | Diatomic | Element symbols in diatomic molecules | `["Br", "Br"]` |
| `geometry` | string | Required | Spatial molecular geometry code | `"regularTetrahedral"` |
| `bondLengths` | object | Required | Bond lengths in Ångströms (Å) | `{"C-H": 1.087}` |
| `bondAngles` | object | Tri+ atomic | Bond angles in degrees (°) | `{"H-C-H": 109.471}` |
| `hybridization` | string | Central atom | Hybrid orbital type | `"sp3"`, `"sp2"` |
| `unpairedElectrons` | number | Optional | Number of radical electrons | `1` |
| `description` | string | Optional | Instructional notes | `"Methane loses a hydrogen..."` |

---

## 2. Geometry Codes

- `regularTetrahedral`: Ideal regular tetrahedron with $109.471^\circ$ bond angles (e.g. $\text{CH}_4$)
- `tetrahedral`: General tetrahedral geometry with customizable bond angles (e.g. $\text{CH}_3\text{Br}$)
- `trigonalPlanar`: Planar triangle with $120^\circ$ bond angles (e.g. $\text{CH}_3\cdot$)
- `diatomic`: Linear diatomic molecule (e.g. $\text{Br}_2$, $\text{HBr}$)
- `atomic`: Single atom / atomic radical (e.g. $\text{Br}\cdot$)
