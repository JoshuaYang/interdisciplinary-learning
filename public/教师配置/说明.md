# 教师维护说明

本项目面向高三学生，以小组形式参与，课时灵活安排。化学知识和简单空间坐标由课堂衔接，JSON 由信息技术老师讲授。先使用完整示例，再让学生修改小文件。范围保持为约定的七个画面、连续动画与自由基圆点标记。

## 文件分工

| 文件 | 维护内容 |
| --- | --- |
| `项目.json` | 项目名称、数据状态、文件清单 |
| `分子参考.json` | 各分子的中文名、元素编号、参考键长键角、来源 |
| `步骤/01.json` 至 `步骤/07.json` | 每步文案、分子实例位置和朝向、原子追踪、断键成键 |
| `../学生任务/*.json` | 学生填写的结构描述与键长 |

七步分别是：初始分子、光照激发、接近甲烷、碰撞反应 ①、接近另一分子 Br₂、碰撞反应 ②、产物总结。不是七个独立的化学反应，第七步也不是链终止。没有增加其他分子百科、终止分支或进一步溴代。

## 学生输入与自动建模

每组维护一个 8—12 行的JSON，填写原子组成、空间构型、键长、键角、名称、化学式、杂化和说明，以及自由基的一个未成对电子。普通中心原子的未成对电子字段可省略。学生无需填写原子编号、坐标、键连接和动画参数。

先共同修改 Br₂ 的键长，再分组解释各分子的构型，导入后用测量栏核对。输入检查针对本项目的六种结构，暂不支持任意分子。周围原子的书写顺序不影响结果。

程序依据教师配置的 `elements` 保持内部原子编号，自动建立单键。CH₄ 用正四面体方向（cosθ=−1/3），CH₃· 用平面上相隔 120° 的方向；键长决定从中心到周围原子的距离。双原子分子按键长的一半放在原点两侧。

CH₃Br 选择`tetrahedral`时读取学生 bondAngles 中的 H—C—Br 角度，并核对 H—C—H 是否相容，生成三个对称氢；选择`regularTetrahedral`时使用理想夹角。这一选择确实改变结构，与当前参考角度不一致时会提示偏差。

生成的局部坐标约定：碳在原点，CH₃· 在 z=0 平面；CH₄ 的 h4、CH₃Br 的 br 在 +z 轴。步骤中的 rotation 将其转到演示朝向。学生输入和导出均只保留结构描述，内部坐标不写回作业。

## 更新键长

老师确定课堂数据后：

1. 在 `分子参考.json` 更新相应 `measurements.value` 与来源状态。
2. 修改学生分子文件中的`bondLengths`；键长参考值只用于比较，不会替代学生输入。键角由学生 bondAngles 提供，参考配置仅用于比较。精确构型允许输入有 0.1° 的舍入误差，具体规则见学生说明。
3. 在 `项目.json` 更新 `dataStatus`，页面会显示该状态。

测量的 `atoms` 有两个编号时计算距离，三个编号时计算夹角，中间编号为角顶点。`tolerance` 的单位与测量一致。偏差超标会提示但仍允许观察，编号、连接或反应对应错误会阻止加载。

## 维护反应步骤

每个实例的 `molecule` 引用学生结构；`position` 是场景平移量，`rotation` 是按 x、y、z 顺序的旋转角（度）。`role` 为 `focus` 或 `context`。

`atomMap` 负责把局部编号对应到全局追踪编号：C、H1—H3 保留在碳骨架；H4 被取走；BrA 留在背景；BrB 进入 HBr；BrC 与碳成键；BrD 成为再生的自由基。

`transition` 的 `breakBonds`、`formBonds` 使用全局编号，必须与前后模型的实际变化一致。`duration` 是教学演示的秒数。视图切换和总结使用 `reframe`、`summary`，不能借切换新增化学反应。

## 开发运行与构建验证

项目采用 React 18 + TypeScript + Vite 构建。在项目根目录运行以下命令即可启动开发服务、执行单元测试或构建生产版本：

```sh
# 启动本地开发服务
pnpm dev

# 运行自动化单元测试（验证核心几何解算、链路装配与自由反应动画引擎）
pnpm test --run

# 构建生产静态包（输出至 dist/）
pnpm build
```

需要拓展课堂反应范围（如构建多中心分子或自定义反应阶段）时，可在应用首页点击进入「**自由化学反应实验台**」，直接使用 118 元素周期表交互式构建分子并编排反应阶段，详见根目录下的 `docs/自由反应实验台与JSON规范.md`。

## 反应依据

主要依据自由基卤代反应机理。另参考 [OpenStax《Organic Chemistry》10.2 自由基卤代反应](https://openstax.org/books/organic-chemistry/pages/10-2-preparing-alkyl-halides-from-alkanes-radical-halogenation)。

引发：Br₂ —光照→ 2Br·。

链增长：Br· + CH₄ → CH₃· + HBr；CH₃· + Br₂ → CH₃Br + Br·。

七个画面只展示引发、两步链增长及产物总结。课件中的链终止分支和继续溴代未纳入当前范围。

## 原子追踪与净反应

为了展示“另一分子溴”而不凭空生成原子，示例从第一步就在背景保留了第二个 Br₂。场景的完整变化是：

`CH₄ + 2Br₂ → CH₃Br + HBr + 2Br·`

其中包含一次引发和一次链增长循环；这是所选粒子的追踪账目，不是用来代替课堂总反应式的产物反应式。

两步链增长相加、消去中间体与链载体后，得到页面第七步的净反应：

`CH₄ + Br₂ → CH₃Br + HBr`

第七步保留两个背景自由基，只把两种产物移到重点位置，不新增反应，也不称为“终止”。

## 动画中的教学简化

- 球棍模型的球体半径为显示尺寸，实际键长由原子中心坐标决定。
- 未成对电子用原子旁的点表示；点的位置只是符号排布，不是电子的真实位置、运动轨道或电子云。
- 平移、旋转、反应时长与粒子之间的间隔用于课堂观察，不代表真实反应条件下的空间分布或速度。
- 保留的分子作刚体移动；反应中保留的 C—H 键在长度保持于端点参考范围内的同时调整方向，展示四面体与平面结构间的变化。
- 断键与成键过程通过连续插值及键的显隐表现；中间画面是机理示意，不是计算得到的过渡态或势能面。
- 测量栏仅在一个步骤结束后显示稳定结构值，不把插值过程中的几何数据当作实验数据。
- 背景粒子降低不透明度只是为了聚焦当前步骤，不表示粒子质量减少、消失或变成其他物种。
