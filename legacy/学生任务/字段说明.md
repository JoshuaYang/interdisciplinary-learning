# 分子配置文件字段说明文档

本目录提供了 6 种分子的配置文件模版（`.json` 格式），文件内仅预置了中文名称 `name`。你需要根据所学化学知识与实验测量数据，自主完成其余字段的填写，保存后在实验平台中上传验证。

---

## 一、配置文件结构分类

根据分子的成键与中心原子特征，分为以下三类结构：

1. **含中心原子的多配体分子**：适用于具有中心碳原子的有机分子或基团（`CH4.json`、`CH3.json`、`CH3Br.json`）。
2. **双原子分子**：适用于由两个原子成键构成的简单分子（`Br2.json`、`HBr.json`）。
3. **单原子自由基**：适用于游离的单原子活性微粒（`Br.json`）。

---

## 二、字段详细定义与书写规范

### 1. `name`（分子中文名称）
- **数据类型**：字符串（`String`）
- **适用分类**：全部微粒
- **规范说明**：微粒的中文名称。模版中已预置，保留原样即可，请勿修改。
- **书写示例**：
  ```json
  "name": "水"
  ```

---

### 2. `formula`（化学式）
- **数据类型**：字符串（`String`）
- **适用分类**：全部微粒
- **规范说明**：微粒的标准化学式。
  - **普通稳定分子**：直接输入元素符号与下标数字。
  - **自由基**：末尾必须带上未成对电子圆点 `·`（输入键盘英文句号 `.` 会自动转换）。
- **书写示例**：
  - 稳定分子：
    ```json
    "formula": "NH3"
    ```
  - 自由基：
    ```json
    "formula": "OH·"
    ```

---

### 3. `center`（中心原子）
- **数据类型**：字符串（`String`）
- **适用分类**：仅含中心原子的分子
- **规范说明**：分子骨架中处于几何中心的成键原子元素符号。
- **书写示例**：
  ```json
  "center": "C"
  ```

---

### 4. `neighbors`（配体周围原子列表）
- **数据类型**：字符串数组（`Array of Strings`）
- **适用分类**：仅含中心原子的分子
- **规范说明**：直接与中心原子成键的周围配体原子元素符号列表。每个原子用独立双引号包裹，数组内元素顺序不影响几何生成。
- **书写示例**：
  ```json
  "neighbors": ["H", "H", "H"]
  ```

---

### 5. `atoms`（原子组成列表）
- **数据类型**：字符串数组（`Array of Strings`）
- **适用分类**：双原子分子、单原子自由基
- **规范说明**：构成该微粒的所有原子元素列表。双原子分子填 2 个元素，单原子微粒填 1 个元素。
- **书写示例**：
  - 双原子分子：
    ```json
    "atoms": ["H", "Br"]
    ```
  - 单原子自由基：
    ```json
    "atoms": ["Br"]
    ```

---

### 6. `geometry`（空间几何构型）
- **数据类型**：字符串（`String`）
- **适用分类**：全部微粒
- **规范说明**：微粒的空间对称几何构型标识。系统支持的标准英文关键词包括：
  - `regularTetrahedral`（正四面体，如 CH₄）
  - `tetrahedral`（四面体构型，如 CH₃Br）
  - `trigonalPlanar`（平面三角形，如 CH₃·）
  - `diatomic`（双原子结构/双原子分子，如 Br₂、HBr；双原子间不存在中心原子及夹角，不建议作为直线形处理，亦兼容 `linear`）
  - `atomic`（单原子自由基，如 Br·）
  
  请结合价层电子对互斥理论、中心原子杂化状态及成键类型选择正确的关键词填入。
- **书写示例**：
  ```json
  "geometry": "diatomic"
  ```

---

### 7. `bondLengths`（共价键键长）
- **数据类型**：键值对对象（`Object`）
- **适用分类**：除单原子外的所有分子
- **规范说明**：各共价键的理论或实测键长，单位为埃（$\text{Å}$，1 $\text{Å} = 10^{-10}\text{ m}$）。
  - 键名格式为 `元素A-元素B`。
  - 数值填写大于 0 的纯数字，严禁附带单位字符或算式。
- **书写示例**：
  - 单一键长类型：
    ```json
    "bondLengths": {
      "C-H": 1.09
    }
    ```
  - 含有多种共价键：
    ```json
    "bondLengths": {
      "C-H": 1.09,
      "C-Br": 1.94
    }
    ```

---

### 8. `bondAngles`（共价键夹角）
- **数据类型**：键值对对象（`Object`）
- **适用分类**：仅含中心原子的分子
- **规范说明**：共价键在三维空间构型中的夹角，单位为度（$^\circ$）。
  - 键角名称格式为 `端基原子1-中心原子-端基原子2`（中心原子位于中间）。
  - 数值填写大于 0 且小于 180 的纯数字。
- **书写示例**：
  - 单一键角类型：
    ```json
    "bondAngles": {
      "H-C-H": 109.5
    }
    ```
  - 多种键角类型：
    ```json
    "bondAngles": {
      "H-C-H": 111.4,
      "H-C-Br": 107.5
    }
    ```

---

### 9. `hybridization`（杂化轨道类型）
- **数据类型**：字符串（`String`）
- **适用分类**：仅含中心原子的分子
- **规范说明**：中心原子的轨道杂化类型标识（如 `"sp3"`, `"sp2"` 等）。
- **书写示例**：
  ```json
  "hybridization": "sp3"
  ```

---

### 10. `unpairedElectrons`（未成对电子数）
- **数据类型**：整数（`Integer`）
- **适用分类**：仅自由基微粒
- **规范说明**：该活性微粒所含有的孤单（未成对）电子个数，填写整数。普通稳定分子无需填写此字段。
- **书写示例**：
  ```json
  "unpairedElectrons": 1
  ```

---

### 11. `description`（反应机理说明）
- **数据类型**：字符串（`String`）
- **适用分类**：全部微粒
- **规范说明**：简述该微粒在甲烷取代反应全流程（链引发、链增长或总结）中所承担的反应角色、转化行为或结构特点。
- **书写示例**：
  ```json
  "description": "简要阐述该分子在反应各阶段中的变化特征与作用机理。"
  ```

---

## 三、填写与校验流程建议

1. **选择文件**：在当前目录下使用纯文本编辑器打开待填写的配置文件（如 `CH4.json`）。
2. **补全属性**：对照上述规范补齐缺失字段，注意 JSON 语法规范（键名需用英文半角双引号包裹，多项之间用半角逗号隔开，末尾项不能带逗号）。
3. **上传校验**：在浏览器打开 `化学/index.html`，点击对应分子卡片或拖入文件，平台将根据空间对称性与物理常数进行自动核验。
