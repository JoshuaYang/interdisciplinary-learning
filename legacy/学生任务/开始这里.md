# 学生任务指南

本项目通过构建分子的空间构型与参数化结构，驱动「甲烷自由基取代反应」的三维可视化。

每个小组负责一种分子或自由基。在 `学生任务/` 目录下已放置各分子的基础配置文件模板（仅预置了中文名称 `name`）。你需要结合化学知识与实验测量数据，自主完成其余字段的填写。

---

## 任务流程

```
[1. 认领分子] ──> [2. 查阅字段说明] ──> [3. 补全配置文件] ──> [4. 页面上传验证]
```

### 1. 认领分子
- 第一组：`CH4.json`（甲烷）
- 第二组：`CH3.json`（甲基自由基）
- 第三组：`CH3Br.json`（一溴甲烷）
- 第四组：`Br2.json`（溴单质）
- 第五组：`HBr.json`（溴化氢）
- 第六组：`Br.json`（溴自由基）

### 2. 查阅规范
详细字段类型、格式要求与结构分类请查阅同目录下的 **[字段说明.md](字段说明.md)**。

### 3. 补全配置文件
使用代码编辑器（推荐 VS Code、Notepad++ 等纯文本编辑器）打开对应的 `.json` 文件，根据化学分子结构填写缺失字段：
- 确定化学式与成键原子
- 确定空间几何构型与中心原子杂化状态
- 填写实测/理论键长与键角数据
- 判断是否包含未成对电子

### 4. 浏览器上传与验证
1. 打开 `化学/index.html`。
2. 在前置核验面板中，点击对应分子的卡片选择填写好的文件（或直接拖入）。
3. 系统将基于空间对称性与几何约束进行自动校验。若校验通过，卡片将打勾并点亮参数；若有偏差，卡片将显示提示指引修改方向。
4. 当 6 个分子全部校验通过后，即可解锁进入完整三维反应全流程演示。
