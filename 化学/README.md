# 甲烷的自由基取代

双击 **index.html** 打开七步三维演示。保留完整文件夹，离线也能使用。

## 学生只用这个文件夹

打开 **[学生任务](学生任务/开始这里.md)**，每组修改自己负责的一个 JSON，**填写原子组成、空间构型、键长、键角、名称、化学式、杂化与说明等内容，坐标自动生成，每份 8—12 行**。页面右上角「加载 JSON」可导入一个或多个分子文件，自动保留其他组的结构与七步动画。

例如：[CH4.json](学生任务/CH4.json) 是甲烷，[CH3.json](学生任务/CH3.json) 是甲基自由基。

## 目录

```text
化学/
├── index.html       打开演示
├── README.md        本说明
├── 学生任务/         6 个小 JSON + 入门说明
├── 教师配置/         参考数据、7 个独立步骤文件、教师说明
├── 参考资料/         原始 PPTX 和手写 PDF
└── 程序/             页面代码、三维库和维护工具
```

学生不需要阅读「教师配置」或「程序」。旧版分子页面、旧的大 JSON、旧压缩包及已替代的文档、生成脚本已清理。

## 使用

- 「连续播放」自动接续七步；「下一步」播放一段后停下；「重播本步」重看当前变化。
- 拖动旋转，滚轮或双指缩放，点击原子查看编号。
- 「键长 / 键角」显示由坐标计算的结构值。
- 导入后可以选择一个分子，下载它的小 JSON。作业不会上传，也不会自动写回磁盘。

**双击打开**使用内置示例。修改学生文件后，通过页面导入才能看到改动；刷新会恢复内置示例。

如有 Python 3，也可在本文件夹运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

打开 <http://127.0.0.1:8765>，刷新或点击「恢复默认结构」会重新读取所有分文件配置。Ctrl+C 关闭服务。

键长目前为已核对来源的参考值，等待化学老师确认。教师维护、自动建模说明和参考来源见 **[教师配置 / 说明.md](教师配置/说明.md)**。
